# Copper State Baptist Church website draft

This is a first-pass, static website draft for review. It is not ready to publish until church leadership verifies the content and fills in all placeholders.

## Files
- `index.html` — Home
- `about.html` — About
- `beliefs.html` — What We Believe
- `salvation.html` — Salvation
- `sermons.html` — Sermons
- `visit.html` — Visit Us
- `contact.html` — Contact
- `assets/css/styles.css` — Design and responsive layout
- `assets/js/main.js` — Mobile navigation and current year

## Before launch
1. Confirm the church's official colors, logo, and preferred photos.
2. Replace placeholder service times, street address, email, and phone.
3. Have church leadership approve the About and doctrinal content.
4. Add the official YouTube channel or sermon links.
5. Connect and test a real contact form; the current contact page is informational only.
6. Test on phones and computers.

The site currently uses Google Fonts from an external source. These can be replaced with system fonts if preferred.
